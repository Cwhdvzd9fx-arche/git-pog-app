## 🚀 Pour lancer la beta

### Option 1 : Script automatique

```bash
./QUICK_START_BETA.sh
```

### Option 2 : Manuel

```bash
# 1. Installer pnpm
npm install -g pnpm

# 2. Installer les dépendances
pnpm install

# 3. Configurer .env (voir env.example.txt)

# 4. Lancer
pnpm dev
```
